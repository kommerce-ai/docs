---
title: "Structuring testing campaigns"
description: "How to lay a test out in Meta so the result is attributable."
---

## One idea, one ad set

Each idea gets its own ad set and its own budget. Versions of that idea live inside it.

This is what makes a verdict attributable: everything inside one ad set shares an audience and a budget, so differences between ad sets are differences between ideas.

## Hold everything else constant

Across the ad sets in a test, keep identical:

- Audience and exclusions
- Placements
- Bid strategy
- Campaign objective

<Warning>
  A test where one idea runs on different placements isn't a test of the idea. You'll attribute a placement effect to your creative and carry that wrong conclusion into the next round.
</Warning>

## Budget type

Default to **lifetime, per ad set**. Predictable, and each idea gets its money regardless of what the others do.

Shared campaign budgets belong in scaling, not testing.

## New campaign or existing

Either works. Name an existing campaign exactly as Meta has it, or create a new one.

<Note>
  Kommerce can't create campaigns. A new campaign is built in Ads Manager or in Kommerce's own publish flow — everything else in a test can be created for you.
</Note>

## Naming

Copy the pattern the brand's live ads already use. Change only the test number, the awareness code, the slug and the version.

Consistent naming is what lets patterns group ads by persona, awareness and angle later. Inconsistent naming quietly destroys that, and you won't notice until you want the analysis.

## Sizes

Statics need 4:5 and 1:1, plus 9:16 if Stories or Reels placements are on. An idea missing the ratio for a placement it's running on will be cropped by Meta, usually through the headline.

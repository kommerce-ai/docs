## Money

| Term | Means |
| --- | --- |
| **AOV** | Average order value |
| **COGS** | Cost of goods. What fulfilling an order costs |
| **CPA** | Cost per acquisition. What an order cost you |
| **CAC** | Customer acquisition cost. Often used interchangeably with CPA |
| **ROAS** | Return on ad spend. Revenue divided by spend |
| **Break-even CPA** | The most an order can cost before it stops making money. The bar |
| **Break-even ROAS** | The same fact as a ratio |

Break-even is not a target. It is the point of indifference. The client's target sits below it, and that gap is the margin.

## Delivery

| Term | Means |
| --- | --- |
| **Impression** | One showing of an ad |
| **CPM** | Cost per thousand impressions |
| **CTR** | Click-through rate |
| **Frequency** | Average times one person saw it |
| **Learning phase** | Meta's early period before delivery stabilises |
| **Placement** | Where an ad appears. Feed, Stories, Reels |

## Structure

| Term | Means |
| --- | --- |
| **Campaign** | Top level. Holds ad sets, sets the objective |
| **Ad set** | Holds ads. Owns audience, placements, often budget |
| **ABO** | Budget set per ad set. The testing default |
| **CBO** | Budget shared across the campaign. A scaling tool |
| **Lifetime budget** | A total for the run |
| **Daily budget** | A per-day amount |

## The funnel

Impression, click, landing page view, add to cart, checkout, order.

Where it breaks tells you what to fix. Only the first two steps are creative problems.

## Tracking

| Term | Means |
| --- | --- |
| **Pixel** | Meta's tracking on your site |
| **Signal** | Whether conversion data is trustworthy |
| **Attribution window** | How long after seeing an ad a sale still counts |

## Testing units

| Term | Means |
| --- | --- |
| **Idea** | One thing being tested. Gets its own ad set and budget |
| **Version** | An execution of an idea. Shares the ad set |
| **Angle** | The claim or positioning being argued |
| **Hook** | The opening line or first frame |
| **Lever** | The thing a version pulls differently |
| **Mode** | Statics, Video, Motion or Trybe creators |

## Awareness

The five levels: **Unaware**, **Problem Aware**, **Solution Aware**, **Product Aware**, **Most Aware**.

They decide what a headline may say. See [Creative strategy](/operator-wiki/creative-testing/strategy).

## Evidence

| Term | Means |
| --- | --- |
| **Learning** | Something a concluded test established |
| **Pattern** | A group of the account's ads, by persona, awareness, angle or page |
| **Exploratory** | An idea with no supporting evidence. Minimum budget |

**Strength:** Strong, Likely, Leaning, Directional, Thin, Against.

**Pattern labels:** Winning, Front-runner, Promising, Losing, Too early. These are chances, not proof.

## Test outcomes

| Term | Means |
| --- | --- |
| **Testing** | First funded run |
| **Confirming** | Second run on fresh spend |
| **Winner** | Passed both |
| **Promising, unproven** | Ran out of funding while still plausible. Not a failure |
| **Inconclusive** | Not enough evidence either way |

## Production

| Term | Means |
| --- | --- |
| **Brief** | What an idea is testing, plus the words and composition |
| **Matched pair** | Two versions identical but for the variable |
| **Blueprint** | A layout generation composes inside |
| **VOC** | Voice of customer. Their words, not the brand's |

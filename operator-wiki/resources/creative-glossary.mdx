## The units

| Term | Means |
| --- | --- |
| **Idea** | One thing being tested — an angle, an audience, an offer. Gets its own ad set and budget |
| **Version** | An execution of an idea. Versions share an ad set and a budget |
| **Angle** | The claim or positioning being argued |
| **Hook** | The opening line or first frame. Does the work of stopping the scroll |
| **Lever** | The thing a version pulls differently |
| **Mode** | Statics, Video, Motion or Trybe creators. Held constant within a test |

<Note>
  Ideas cost money; versions don't. Five versions of one angle share a budget. Five angles need five budgets.
</Note>

## Awareness

The five levels — **Unaware, Problem Aware, Solution Aware, Product Aware, Most Aware** — decide what a headline is allowed to say. See [Awareness levels](/operator-wiki/creative-testing/awareness-levels).

## Evidence

| Term | Means |
| --- | --- |
| **Learning** | Something a concluded test established. Citable by later briefs |
| **Pattern** | A group of the account's ads, by persona, awareness, angle or page |
| **Evidence tag** | Where a claim came from |
| **Exploratory** | An idea with no supporting evidence. Allowed, but minimum budget |

**Evidence strength:** Strong · Likely · Leaning · Directional · Thin · Against.

**Pattern labels:** Winning · Front-runner · Promising · Losing · Too early. These are chances, not proof.

## Test outcomes

| Term | Means |
| --- | --- |
| **Testing** | First funded run |
| **Confirming** | Second run on fresh spend, proving it wasn't luck |
| **Winner** | Passed both. Ready to scale |
| **Promising, unproven** | Ran out of funding while still plausible. **Not a failure** |
| **Inconclusive** | Not enough evidence either way |

## Production

| Term | Means |
| --- | --- |
| **Brief** | What an idea is testing, plus the words and composition |
| **Matched pair** | Two versions identical but for the variable |
| **Blueprint / template** | A layout generation composes inside |
| **Backplate** | The generated scene a product sits in |
| **VOC** | Voice of customer — their words, not the brand's |

## Hypothesis

> We believe **[change]** will **[result]** compared with **[control or break-even]**, because **[reason, with evidence]**. Against it: **[strongest counter-evidence]**.

Up to 600 characters. If it doesn't fit, it's usually testing more than one thing.

<Note>
  The "against it" clause is what makes the test honest. If nothing argues against your idea, you probably haven't read the evidence.
</Note>

## Test plan

| Section | What goes in it |
| --- | --- |
| **Overview** | Two or three sentences: what it tests and the strongest evidence |
| **Brand guidelines** | Five bullets — voice, look, product on screen, claims, never |
| **Title** | Test number · persona · angle · what's being contrasted |
| **Volume** | Ad sets × creatives = total ads, with budget and per-day figure |
| **Hypothesis** | As above |
| **Why** | The business problem in numbers |
| **Evidence** | 3–10 rows, real numbers with spend, each with a strength |
| **Plan** | Persona, awareness, angle, the variable, what's held constant, campaign, budget type |
| **Success** | The bar, and the best current ad to beat |
| **Creative briefs** | One row per ad |
| **QA** | Tick only what's true. Open items become blockers |

## Creative brief row

| Field | What it holds |
| --- | --- |
| **Headline · CTA** | Meta headline with character count, then the button |
| **Visual** | The composition — photo, product's role, where the offer sits |
| **Image copy** | On-image headline, subline, offer line |
| **Lever · reference** | What this version pulls, with real links to real ads |
| **Ad copy** | Meta primary text with character count. Aim ≤125, hard limit 400 |

<Warning>
  Never invent an ad reference. Link to a real ad in the Meta Ad Library or your saved research, or leave it out.
</Warning>

## Creator brief

**Profile** matching the persona · **Talking points** in customer phrasing · **Must say** with approved claims verbatim · **Never say** with banned words.

Direction, not a script — the creator says it their own way.

## Evidence row

> **[Tag]** — [what it showed, with real numbers and spend] — *[strength]*

"4 purchases at $32.08 on $128 spend — directional" is evidence. "Converts well" isn't.

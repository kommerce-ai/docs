## From Claude

Operators can drive Kommerce from Claude through the MCP connection — read performance, write briefs, generate and review creatives, run tests, publish paused ads. See [Kommerce MCP](/operator-wiki/resources/mcp).

<Warning>
  MCP is operator-only. Brand logins are refused — don't tell a client they can connect.
</Warning>

## The library

[github.com/kommerce-ai/kommerce-library](https://github.com/kommerce-ai/kommerce-library) holds the written-down procedures in plain markdown, organised by job, with `skills/`, `sops/` and `processes/` in each.

You can point Claude straight at it:

> *"Read github.com/kommerce-ai/kommerce-library and run the Meta account audit on this account."*

It also works the other way — if a process only exists in your head, Claude will interview you and write it down, and you open a pull request.

## Reading list

The frameworks the house style rests on: Eugene Schwartz, *Breakthrough Advertising* (awareness). John Caples, *Tested Advertising Methods* (appeals, headline testing). Copyhackers on message mining.

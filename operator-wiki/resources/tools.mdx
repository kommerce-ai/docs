## The library

[github.com/kommerce-ai/kommerce-library](https://github.com/kommerce-ai/kommerce-library) holds written-down procedures in plain markdown, organised by job. Each job folder has `skills/` for single tasks, `sops/` for multi-step processes, and `processes/` for maps of work not yet turned into either.

You can point Claude straight at it:

> "Read github.com/kommerce-ai/kommerce-library and run the Meta account audit on this account."

It works the other way too. If a process only exists in your head, Claude will interview you and write it down, and you open a pull request.

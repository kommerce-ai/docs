You can drive Kommerce from Claude instead of clicking through the app — read performance, write briefs, generate and review creatives, run tests, and publish paused ads to Meta.

It's the same product with the same rules. Nothing you can do in Claude bypasses a gate the app would have applied.

<Warning>
  **Operator accounts only.** Brand logins can't connect — they're told *"This account cannot connect Claude."*

  Brand access is built into the plan but hasn't shipped. Don't tell a client they can connect yet.
</Warning>

## Connecting

Add Kommerce as a connector in Claude and complete sign-in. You are asked to approve what the connection may do:

- Read your brand guide, products, personas, briefs, creatives and landing pages
- Read your Meta ad performance
- Comment on, review and approve creatives and landing pages
- Review and approve work

If sign-in fails, two messages tell you which side the problem is on:

| Message | Means |
| --- | --- |
| *"Could not reach Kommerce."* | Network — check your connection, start again from Claude |
| *"Could not check this account."* | Kommerce side — wait a minute, start again from Claude |
| *"This account cannot connect Claude."* | The account is not an operator account |

## Start with the brand

Everything is scoped to one brand at a time. Say which brand you're working on before anything else — otherwise Claude is guessing, and guessing across brands is exactly what this is built to prevent.

<Note>
  Ask it to read the brand guide before writing copy, and the performance evidence before proposing an angle. The account already knows what converts — that's the difference between a useful draft and a generic one.
</Note>

## What it can do

| Area | Examples |
| --- | --- |
| **Read** | Brand guide, products, personas, briefs, creatives, landing pages, Meta performance |
| **Write** | Briefs, personas, brand guide, learnings |
| **Generate** | Creatives, test creatives — always quoted before spending |
| **Review** | Score, comment on a region, regenerate, approve or reject |
| **Test** | Suggest, create, brief, generate, publish, read the daily calls, close out |
| **Publish** | Prepare and publish to Meta — always paused |
| **Research** | Competitor ads and curated boards |

## What stays with a person

<CardGroup cols={2}>
  <Card title="Spending is confirmed twice" icon="shield-check">
    Generation returns a **quote** first and spends nothing. It only runs when you re-request with confirmation.
  </Card>
  <Card title="Publishing never spends" icon="pause">
    Everything published through MCP is created **paused**. Someone has to activate it in Ads Manager.
  </Card>
</CardGroup>

It also cannot create campaigns. A new campaign is built in Ads Manager or in Kommerce's own publish modal.

<Warning>
  Competitor research is billed per ad returned, so the number of results you ask for **is** the price. Asking for a big sample to "see what's there" costs real money — it isn't browsing.
</Warning>

## Why actions are attributed

Every action records who did it, for which brand, and what happened. A brief that appeared overnight or a budget that moved is traceable rather than mysterious.

This matters more here than in the app, because Claude can do a lot very quickly — the record is what makes that safe to hand out.

## Before you trust a long agent run

<Steps>
  <Step title="Check the brand">
    Make sure it's working on the brand you meant. Everything after that inherits it.
  </Step>
  <Step title="Read quotes, don't skim them">
    The quote is the last gate before credits move.
  </Step>
  <Step title="Verify in the app">
    Published ads, closed tests and new learnings all show up in Kommerce. Check there rather than trusting the chat transcript.
  </Step>
</Steps>

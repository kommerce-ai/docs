The brief comes first. It states what each idea is testing, so that when the verdict arrives you know what was proven.

A weak creative makes a test read as a loss for the idea when it was really a loss for the execution. The brief is where you prevent that.

## Before writing a word

Read what the account already knows.

| Read this | For |
| --- | --- |
| **Brand** | Personas, products, voice, guardrails, unit economics |
| **Learnings** | What past tests established |
| **Patterns** | Which persona, awareness, angle and page groups are working |
| **Past tests** | Questions already answered |
| **Account numbers** | Spend, ROAS, AOV, CTR, orders |
| **Competitor ads** | What rivals repeat and keep running |

Every claim that reaches the brief carries a tag saying where it came from. A line with no tag does not belong in the hypothesis or the evidence.

## The plan

A test plan has a fixed shape. Each part answers a question someone will ask later.

| Section | What it holds |
| --- | --- |
| **TL;DR overview** | Two or three sentences, then one bullet per test |
| **Brand guidelines** | Five bullets: voice, look, product on screen, claims, never |
| **Title** | Test number, persona, angle, what is contrasted |
| **Volume** | Ad sets × creatives = total ads, with budget and per-day figure |
| **Hypothesis** | Up to 600 characters |
| **Why** | The business problem in numbers |
| **Evidence** | Three to ten rows, real numbers with spend |
| **Plan** | Persona, awareness, angle, the variable, what is held constant |
| **Success** | The bar, and the best current ad to beat |
| **Creative briefs** | One row per ad |
| **QA** | Tick only what is true |

## The hypothesis

> We believe **[change]** will **[result]** compared with **[control or break-even]**, because **[reason, with evidence]**. Against it: **[strongest counter-evidence]**.

Most people drop the last clause. It is the one that makes the test honest.

## Evidence rows

> **[Tag]** — what it showed, with real numbers and spend — *strength*

"4 purchases at $32.08 on $128 spend, directional" is evidence. "Converts well" is not.

Strength is one of: Strong, Likely, Leaning, Directional, Thin, Against. Under about ten orders, nothing is better than directional.

## OLSEN levers

A lever is how a version argues its angle. Record it in the creative block.

| Lever | What it pulls on |
| --- | --- |
| **O · Offer** | The deal, the gift ladder, value against price |
| **L · Logic** | The mechanism, the numbers, the proof |
| **S · Social** | Other people, belonging, reviews |
| **E · Emotion** | Relief, pride, the moment |
| **N · Novelty** | New format, unexpected object, pattern interrupt |

Each hook in a version should pull a different lever, unless the lever is the variable being tested.

## Fair-test rules

A test is only readable if both sides got a fair shot.

<Steps>
  <Step title="Change only the variable">
    If A is offer-led and B is angle-led, both still show the same offer and the same product truth. Only the lead differs.
  </Step>
  <Step title="Match volume">
    The same number of creatives per version, at similar production quality.
  </Step>
  <Step title="Build each side's strongest creative">
    Use the account's best evidence for both. A straw man version wastes the whole test.
  </Step>
  <Step title="Name what each version must not do">
    For example, "B never mentions the gifts before the call to action."
  </Step>
</Steps>

## The creative row

| Field | What it holds |
| --- | --- |
| **Ad headline · CTA** | Meta headline with character count, then the button |
| **Image visual** | The composition. Where the product reveal and the offer sit |
| **Text overlay** | On-image headline, subline, offer line |
| **Lever · reference** | The OLSEN lever, then links to real ads |
| **Ad copy** | Meta primary text with character count |

Describe a composition a designer could execute without guessing. Describe the idea, not render settings.

<Warning>
  Never invent an ad reference. Link to a real ad in the Meta Ad Library or your saved research, or leave the field empty.
</Warning>

## Quality bar

- House voice. Plain, confident, direct-response. Short sentences.
- Specific numbers, not vague claims.
- Only claimable numbers. Prices and stats must trace to product facts or account data.
- Open at the version's awareness level.
- Video body moves: false belief, mechanism, proof, product as the easiest fix, soft close.

## QA before it goes anywhere

Tick only what is true. Anything open becomes a blocker on the plan.

Checks cover the plan fields, the creative rows, and for creator work the profile, deliverables, hooks to film, talking points, usage and rights, and product shipping.

Creative testing is the centre of Kommerce. Onboarding and research exist to feed it; scaling exists to cash in what it proves.

You test **ideas**. Each idea runs in its own ad set with its own budget, against a bar. Kommerce reads the account daily and tells you what each one deserves.

## The loop

<Steps>
  <Step title="Test generation">
    Kommerce suggests what to test next, based on what the account already shows. [See how](/operator-wiki/creative-testing/generating-tests)
  </Step>
  <Step title="Creative strategy">
    Each idea gets a brief — the angle, audience and hook it exists to prove. [See how](/operator-wiki/creative-testing/creative-briefs)
  </Step>
  <Step title="Content generation">
    Briefs become ads. [See how](/operator-wiki/creative-testing/content-generation)
  </Step>
  <Step title="Publishing in Meta">
    Everything goes live paused. Nothing spends until a person says so. [See how](/operator-wiki/performance/publishing-tests)
  </Step>
  <Step title="Optimisation">
    Read the daily calls, approve what makes sense. [See how](/operator-wiki/performance/monitoring-tests)
  </Step>
</Steps>

Winners leave this loop through [Scaling](/operator-wiki/performance/scaling).

## The one number that matters

Every decision turns on **break-even CPA** — what an order can cost before it stops making money.

<Warning>
  This is a break-even point, not a goal. Set it optimistically and Kommerce will kill ideas that were profitable and promote ones that weren't.
</Warning>

## Ideas, versions, and why the difference costs money

This trips people up more than anything else in testing.

<CardGroup cols={2}>
  <Card title="An idea" icon="lightbulb">
    One thing you're testing — an angle, an audience, an offer. Each idea needs its own ad set and its own budget.
  </Card>
  <Card title="A version" icon="copy">
    A different execution of the same idea. Versions share one ad set and one budget.
  </Card>
</CardGroup>

So **"make five more versions" is cheap. "Test five more ideas" is not.** Five versions of one angle share a budget; five different angles need five budgets, and each one needs enough spend to prove anything.

<Tip>
  When budget is tight, the winning move is usually fewer ideas with enough money behind each, not more ideas sharing a budget too thin to produce a verdict on any of them.
</Tip>

## Setting up a test

You'll choose:

| Choice | Options |
| --- | --- |
| **What you're changing** | The ads, the landing page, or the offer |
| **What you want to learn** | Which audience, which angle, which offer, or where you're losing people |
| **How versions compete** | Each against the break-even bar, or against each other |
| **Budget** | Lifetime or daily, set per ad set or shared across the campaign |
| **How bold to be** | Cautious, balanced, or bold |

**Cautious / balanced / bold** controls how much evidence Kommerce wants before it acts. Bold calls things sooner and is wrong more often. Cautious spends more before deciding.

<Note>
  Pick bold when creative is cheap and you want throughput. Pick cautious when each test costs real money to produce, or when the client will ask you to defend the call.
</Note>

## Everything is attributed

Every action on a test is recorded against a person, against Kenny, or against the system. A budget change you didn't make is traceable, not mysterious.

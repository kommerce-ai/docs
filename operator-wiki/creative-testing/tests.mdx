The brief says what you want to learn. The test is how Kommerce runs it.

## Check the shape first

Before creating anything, ask Kommerce for the test idea. It returns the bar, the budget and the stop rule. Use those numbers in the plan rather than inventing your own.

You tell it the goal, the persona, the awareness level and how many versions you want.

## What a test holds

| Field | What it is |
| --- | --- |
| **Title** | Test number, persona, angle, what is contrasted |
| **Goal** | Audience, angle, offer, or finding a leak |
| **Hypothesis** | Up to 600 characters |
| **Persona** | Exactly one |
| **Awareness** | Exactly one of the five levels |
| **Angle** | The claim being argued |
| **Format** | Image for statics. Video for video, motion and creator work |
| **Versions** | One per idea, each with a label and a brief kind |
| **Evidence** | Up to ten rows, each tagged and sourced |
| **Page, offer, price** | Where traffic goes and what it buys |
| **Budget type and total** | How the money is held |

<Note>
  Kommerce stores one persona and one awareness level per test. If a test genuinely needs two, split it into two tests, or record the primary one and note the second in the hypothesis.
</Note>

## Versions are ideas

Each version gets its own ad set and its own budget. Different executions of a version share that budget.

So five executions of one angle cost one budget. Five angles cost five.

## Budget

Default to lifetime budgets set per ad set.

<Warning>
  A shared campaign budget will starve one side of a test before it produces a verdict. Meta moves money toward whatever looks best early. You are buying information, and those two goals conflict.
</Warning>

Each idea gets about two and a half times break-even CPA. Kommerce also reserves enough to confirm whatever passes, so it will refuse to launch an idea it could not afford to prove.

## Strictness

Cautious, balanced or bold. This sets how much evidence Kommerce wants before it acts.

Bold calls things sooner and is wrong more often. Cautious spends more before deciding.

Pick bold when creative is cheap and you want throughput. Pick cautious when each test costs real money to produce, or when the client will ask you to defend the call.

## Naming the ads

Copy the pattern the brand's live ads already use. Change only the test number, the awareness code, the slug and the version.

Consistent naming is what lets patterns group ads by persona, awareness and angle later.

## The order of operations

<Steps>
  <Step title="Check the test idea">
    Get the bar, budget and stop rule before writing them into the plan.
  </Step>
  <Step title="Show the versions, budget and bar to whoever owns the money">
    This is a decision, not a formality.
  </Step>
  <Step title="Create the test">
    It is a draft. Nothing is running.
  </Step>
  <Step title="Write a brief per version">
    Each one carries what it says and what it shows.
  </Step>
  <Step title="Stop there">
    Generating creative and publishing are separate deliberate steps.
  </Step>
</Steps>

## Using ad sets that already run

You can point a test at live ad sets instead of launching new ones. Kommerce reads them as ideas and applies the same rules.

This is the fastest way to get value from an account you have just taken over.

Every idea in a test needs a brief. A brief isn't a creative wish-list — it's a statement of **what this idea is testing**, so that when Kommerce calls it you know what was actually proven.

## Draft the briefs

Kommerce can draft a brief for every idea that doesn't have one yet, from the brand guide and what the test is trying to learn. Read each one before generating anything.

A brief carries the **angle**, the **hooks** and the **call to action** — the same three things both studios work from.

## Change one thing at a time

This is the discipline the whole test depends on.

<Warning>
  If one idea changes the angle *and* the audience *and* the format, the result tells you nothing useful. You'll know it won or lost — you won't know which change did it, so you can't build on it.

  Change one thing per idea. Different executions of the same idea belong together, sharing a budget.
</Warning>

Labelling matters mechanically, not just for tidiness. Kommerce reads each idea's angle, audience and format when it suggests what to iterate on — an unlabelled idea produces vaguer suggestions.

## Write against evidence, not instinct

Before writing, read what the account already knows:

- **Patterns** — every ad in the account grouped by audience, awareness, angle and page, marked against break-even
- **Learnings** — what previous tests and patterns have established, each one citable
- **Performance evidence** — a summary built for exactly this, with each claim traceable

<Tip>
  Note which learning or pattern a brief is built on. When the test closes, anyone can trace the result back to the reasoning — and a brief that contradicts something you already learned shows up before it spends money, not after.
</Tip>

## Where the brief comes from

Three routes, same output:

| Route | Use it when |
| --- | --- |
| **Generated** | The usual path — written from brand context and the test goal |
| **Uploaded** | The brief already exists as a document |
| **Reference ad** | You are working from an ad that already performs |

## Layout is a separate decision

A brief doesn't need to invent a layout. Kommerce ranks templates for the brand, and attaching one makes generation build inside that structure instead of improvising.

<Note>
  Generating from a brief **is** the sign-off — there's no separate approval step. Approving one ahead of production, or rejecting it outright, is a separate deliberate action.
</Note>
